# New_New_Member_Project (KiCad)
This directory contains submissions for the first half of the hardware subteam new member projects where members takes an example circuit schematic, copy it on KiCad, and then make a PCB of the schematic. Use schematics in the '_Schematics' folder and follow the instructions below. 

### (New) New Member Project:
1. Please select one schematic from this zip folder (you are welcome to do more)
2. Please build the entire circuit in KiCad
3. Include some info like your name and the circuit number in the info boxes (bottom right corner) of the blueprint
4. After you have finished the schematic then build the pcb
5. To select a part footprint simply look up what footprint sounds reasonable for a component of that size or type, given the circuit it is being used for (things like current, frequency, global voltage, ect.)
6. Ensure your design pass ERC (Electrical Rules Check) and DRC (Design Rules Check)
7. Afterwards, make a .ZIP of your work.

Let your leads know when you have finished.
