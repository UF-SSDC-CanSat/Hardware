# PocketQube PCBs
This folder will contain the KiCAD project for the PocketQube. The following sensors are needed on it:

1. Microprocessor: **ESP32-C6-WROOM-1U**
2. Temperature / Barometer Sensor: **BMP581**
3. Current and Voltage Monitor: **BQ28Z610**
4. Gyroscope / Accelerometers: **ICM-42686-P**
5. Magnetometer: **BMM350**
6. GPS Module: TBD
7. Servo: **SG90** (x2)
