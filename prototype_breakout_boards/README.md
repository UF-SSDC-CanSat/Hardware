# Prototype_Breakout_Boards
For boards that fit the requirement that pins are more than 8mm apart, these can be made into daughter boards that can be printed out at UF. 
Each folder should be a different daughter board project. 

- Please follow the DRC by [Voltera-V One](https://github.com/GreenShoeGarage/Voltera-V-One-KiCAD-DRCs)
