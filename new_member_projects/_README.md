# New_Member_Project (KiCad / Altium)
This directory contains submissions for the second half of the PCB project for new member of the SSDC hardware subteam. Members are expected to make a PCB for either a beacon board or a battery board on either Alitum of KiCad. 

### New Member Project:
1. Choose whether to use Altium or KiCad for this project.
2. Read the (documentation)[new_member_projects\\_CanSat_Electrical_New_Member_Projects.pdf] to install Altium or to get instructions for the project. Keep note to the recommendations and tricks.
3. When completed with no ERC or DRC errors. Put a .ZIP file of your project into this directory.

Let your leads know when you have finished.
